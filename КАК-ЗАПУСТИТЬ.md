# Как запустить бота «Общество тайн» — пошагово, с нуля

Эта инструкция для человека, который **никогда не создавал Telegram-бота**.
Ничего программировать не нужно: все файлы уже готовы, надо только зарегистрировать бота, заполнить несколько полей и нажать одну кнопку.

Время: примерно **1–1,5 часа** (из них 20 минут — регистрации и ожидание).
Деньги: **сервер ~300–500 ₽/мес** + домен (можно бесплатно, см. шаг 4).

---

## Сначала — простая картинка: из чего состоит бот

Чтобы не путаться, держите в голове три вещи:

| Что это | Простыми словами | Кто даёт |
|---|---|---|
| **Бот** | аккаунт в Telegram, от имени которого пишет «Общество тайн» | вы сами, через @BotFather (бесплатно, 2 минуты) |
| **Сервер** | маленький компьютер, который круглосуточно работает и «держит» бота | арендуете у хостинга (VPS), ~300–500 ₽/мес |
| **Prodamus** | приём денег с карты и автосписания | ваш уже существующий кабинет Prodamus |

Сервер нужен потому, что кто-то должен принимать от Prodamus сигнал «человек оплатил» в любое время суток и сразу выдавать ссылки. Обычный компьютер/телефон для этого не подходит — он выключается.

**Без сервера никак**, но есть лайфхак: если совсем не хочется этим заниматься — сделайте шаги 1–3 сами, а шаги 4–7 попросите выполнить любого знакомого «технаря» по этой инструкции (там 15 минут работы).

## Шаг 1. Создаём бота в Telegram (5 минут)

1. Откройте Telegram, в поиске найдите **@BotFather** (у него синяя галочка).
2. Нажмите **Start** (или отправьте `/start`).
3. Отправьте команду:
   ```
   /newbot
   ```
4. Бот спросит **имя** — напишите то, что будут видеть люди:
   ```
   Общество тайн
   ```
5. Бот спросит **username** (имя в ссылке). Оно должно быть латиницей и заканчиваться на `bot`, например:
   ```
   obschestvo_tayn_bot
   ```
   Если занято — придумайте другое, например `tayny_club_bot`.
6. В ответ придёт сообщение с **токеном** — длинная строка вида
   `7894561230:AAH-пример_пример_пример`.
   **Скопируйте её и сохраните в заметки.** Это «пароль» от бота, никому не показывайте.
   Потеряете — можно перевыпустить у BotFather (`/mybots` → ваш бот → API Token).

7. Там же, у BotFather, сделайте бота аккуратным (по желанию):
   - `/setdescription` — текст, который видят до нажатия Start;
   - `/setuserpic` — аватар клуба;
   - `/setcommands` — бот сам пришлёт меню команд при запуске, так что этот пункт можно пропустить.

**Не закрывайте чат с BotFather** — он ещё понадобится в шаге 4.

## Шаг 2. Канал и чат (10 минут)

Бот выдаёт доступ в **два места**: закрытый канал и чат обсуждений.

1. Создайте **закрытый канал** (Новый канал → Название «Общество тайн» → **Частный**).
2. В настройках канала: **Администраторы → Добавить администратора → найдите своего бота** по username → добавьте.
   Галочки, которые обязательно включить:
   - ✅ **Приглашать пользователей по ссылке** (без этого бот не создаст ссылки!)
   - ✅ **Блокировать участников** (без этого бот не сможет исключать тех, кто не оплатил)
   - остальное — на ваше усмотрение.
3. Создайте **закрытый чат** для обсуждений (или привяжите обсуждения к каналу: в канале → Управление → Обсуждение).
4. Бота добавьте **администратором и туда**, с теми же двумя галочками.

### Как узнать ID канала и чата

Есть два способа:

**Способ А (проще):** добавить в чат бота **@userinfobot** — он сразу пришлёт ID чата, в котором находится. Потом его можно удалить.

**Способ Б:** после установки бота (шаг 6) написать в канале и в чате команду `/chatid` — бот ответит своим ID.

ID канала выглядит как `-1001234567890` (или `@username_kanala`, если канал публичный по ссылке).

### Ваш личный Telegram ID

Он нужен, чтобы бот присылал вам уведомления об оплатах.
Напишите **@userinfobot** в личку — он ответит числом вида `123456789`. Это и есть ваш ID.

## Шаг 3. Настройки в Prodamus (15 минут)

Нужно три вещи: **адрес платёжной формы**, **секретный ключ** и **ID подписного товара**.

1. Войдите в кабинет Prodamus. Посмотрите на адрес страницы в браузере — он вида
   `https://ваша-форма.payform.ru/`. Вот это и есть **адрес платёжной формы** (скопируйте целиком, со `https://` и слэшем на конце).
2. Найдите **секретный ключ**: Настройки → (секция вашей платёжной страницы) → поле «Секретный ключ». Скопируйте.
3. Создайте **подписной товар** (это включает автосписания):
   Настройки → **Подписки** → создать подписку → название «Общество тайн», цена **790 ₽**, интервал **30 дней** (или 1 месяц), количество автосписаний — на ваше усмотрение.
   После сохранения у подписки будет **ID** (число, например `618988`). Скопируйте его.
4. Позже (в шаге 7) вы впишете в Prodamus адрес, который выдаст установщик.

> Если полей «Подписки» в кабинете нет — значит клубный функционал не подключён (робот автосписаний у Prodamus платный: 1000 ₽ + 2000 ₽ + 1%). Бот работает и без него: **люди платят каждый месяц сами**, а бот присылает три напоминания (за 3 дня, в день окончания и на следующий день) с кнопкой сразу на оплату. Это бесплатно. Письмо в поддержку с вопросами про бесплатные варианты — в файле `ПИСЬМО-В-PRODAMUS.md`.

## Шаг 4. Сервер (15 минут, один раз)

Сервер = арендованный компьютер в дата-центре. Нужен самый дешёвый.

### Где взять
Любой российский хостинг, где есть «VPS»: **Timeweb Cloud**, **Beget**, **reg.ru**, **Aeza**, **FirstVDS**. Ориентир по цене — 300–500 ₽/мес.

Что выбрать при заказе:
- **ОС: Ubuntu 24.04** (или 22.04) — важно, остальное не так критично;
- **1 CPU, 1–2 ГБ RAM, 10 ГБ диска** — с запасом;
- оплата — как удобно.

Через 1–5 минут после оплаты на почту придёт письмо с данными:
**IP-адрес** (например `185.42.10.77`), **логин** `root` и **пароль**.

### Домен: можно бесплатно
Prodamus требует адрес с `https://`. Покупать домен необязательно: установщик сам предложит бесплатный вариант вида
`185.42.10.77.nip.io` — он работает и сертификат безопасности выдаётся автоматически.

Если хотите красивый адрес (`club-vash-domen.ru`) — купите домен (200–900 ₽/год) у того же хостинга и в его панели добавьте **A-запись** на IP сервера. Тогда на вопрос про домен в установщике введите его.

## Шаг 5. Загружаем файлы на сервер (10 минут)

Файлы бота — папка `obshchestvo-tayn-bot` (та, что вы получили). Их надо положить на сервер в папку `/opt/obshchestvo-tayn`.

### Как это сделать без командной строки (рекомендую)

1. Скачайте **FileZilla** (бесплатно, filezilla-project.org) или **WinSCP**.
2. В программе создайте подключение:
   - Хост (Host): IP сервера из письма
   - Имя пользователя: `root`
   - Пароль: из письма
   - Порт: `22`
   - Нажмите «Быстрое соединение».
3. Слева — ваш компьютер, справа — сервер. Справа зайдите в `/opt/`, создайте папку `obshchestvo-tayn`
   (в FileZilla: правой кнопкой в правом окне → «Создать каталог»).
4. Выделите **все файлы и папки** из папки `obshchestvo-tayn-bot` у себя на компьютере и перетащите в правое окно, в `/opt/obshchestvo-tayn`. Дождитесь окончания загрузки.

Готово — файлы на сервере.

### Если есть знакомый технарь
Ему достаточно: `scp -r obshchestvo-tayn-bot root@IP:/opt/obshchestvo-tayn` или `git clone`.

## Шаг 6. Одна команда — и бот работает (10 минут)

Нужно «войти» на сервер и запустить установщик. Это выглядит страшно, но это буквально две строки.

1. У хостинга в панели найдите кнопку **«Консоль»** / **«VNC»** / **«Терминал»** (у всех есть) — откроется чёрное окно прямо в браузере. Ничего устанавливать не надо.
   (Альтернатива для Windows: программа PuTTY или встроенный PowerShell — команда `ssh root@IP`.)
2. Введите логин `root` и пароль из письма (пароль при вводе не отображается — это нормально, просто вставьте и нажмите Enter).
3. Вставьте одну строку и нажмите Enter:

```bash
cd /opt/obshchestvo-tayn && bash deploy/install.sh
```

4. Установщик начнёт задавать вопросы. На каждый — вставьте своё значение и Enter:

| Вопрос | Что вставить |
|---|---|
| Токен бота от @BotFather | токен из шага 1 |
| Ваш Telegram ID | число от @userinfobot |
| ID закрытого канала | `-100…` или `@username` из шага 2 |
| ID чата обсуждений | `-100…` из шага 2 |
| Адрес платёжной формы | из шага 3 |
| Секретный ключ платёжной страницы | из шага 3 |
| ID подписного товара | число из шага 3 (если пусто — Enter) |
| Код интеграции SYS | просто Enter |
| Домен | просто Enter (согласиться на бесплатный `.nip.io`) |

5. Дальше всё само: установится Docker, скачаются библиотеки, запустится бот, настроится HTTPS. Это 3–7 минут, на экране будут мелькать строки — это нормально.

6. В конце установщик напишет зелёным:

```
Готово!
Адрес для Prodamus (вписать в ДВА поля уведомлений):
   https://185.42.10.77.nip.io/prodamus/webhook
```

**Скопируйте этот адрес** — он нужен в следующем шаге.

## Шаг 7. Связываем с Prodamus (5 минут)

В кабинете Prodamus:

1. **Настройки** → поле **«URL-адреса для уведомлений»** → вставьте адрес из шага 6.
2. Там же раздел **«Подписки»** → поле **«URL-адреса для уведомлений о совершении оплат по подписке»** → вставьте **тот же адрес**.
3. Сохраните.
4. Нажмите кнопку **«Тестировать запрос»** (рядом с полем). Если всё хорошо — придёт ответ `success`.

> Если тест не проходит — почти всегда причина в адресе: опечатка, `http` вместо `https` или забыли `/prodamus/webhook` в конце.

## Шаг 8. Проверяем, что всё работает (5 минут)

1. Откройте своего бота в Telegram (ссылка `t.me/ваш_username`) → **Start**.
   Должно прийти приветствие «Добро пожаловать в «Общество тайн»!» и кнопка «Вступить в Общество тайн».
2. Напишите боту **/admin** — должна открыться админ-панель. Если не открылась — ваш ID в `ADMIN_IDS` неверный.
3. **Проверка оплаты.** Есть два способа:
   - **Боевой:** нажмите «Вступить» → «Оплатить 790 ₽» → оплатьте реальной картой. Бот должен прислать ссылки в канал и чат, а вам — уведомление «🎉 Новая оплата». Деньги можно потом вернуть через Prodamus.
   - **Без денег** (если есть доступ к консоли сервера): наберите
     ```bash
     cd /opt/obshchestvo-tayn && docker compose exec bot python scripts/simulate_payment.py --tg-id ВАШ_ID
     ```
     Это «поддельная оплата» с правильной подписью — бот отработает всё, кроме реального списания.
4. Проверьте кнопку **«Отменить подписку»**: /status → «Отменить подписку» → «Да, отменить». Должно прийти «Готово, подписка отменена», а вам — уведомление.
   <i>В бесплатном режиме (автосписания не подключены) бот спросит «Не продлевать подписку?» и ответит «Хорошо, продлевать не будем» — напоминания прекратятся, доступ закончится ровно в оплаченную дату.</i>

Если все 4 пункта прошли — **бот запущен и работает**. Дальше можно ничего не делать: он сам напоминает о продлении, сам выдаёт доступ и сам исключает неоплативших.

## Шаг 9. Что теперь делать каждый день

**Ничего 🙂** Бот работает круглосуточно. Вам будет приходить:

- 🎉 «Новая оплата» — когда кто-то вступил;
- 🔁 «Продление» — когда списались деньги за следующий месяц;
- 🚪 «Участник отменил подписку» — чтобы вы знали;
- ⚠️ сообщения об ошибках (редко, но лучше не игнорировать — там будет написано, что делать).

Полезные команды в боте (только для вас):

| Что | Как |
|---|---|
| Сколько участников и выручка | `/admin` → 📊 Статистика |
| Подарить доступ (конкурс, подарок, оплата мимо Prodamus) | `/admin` → 🎁 Выдать доступ |
| Убрать человека из клуба | `/admin` → 🚫 Забрать доступ |
| Отключить кому-то автосписание | `/admin` → 🔁 Отменить автосписание |
| Создать промокод на скидку | `/admin` → 🏷 Промокоды → ➕ Создать |
| Найти участника | `/admin` → 👤 Найти участника |

## Если нужно поменять цену или тексты

**Цену** — в файле `.env` на сервере (строка `PRICE=790`), плюс не забудьте поменять сумму в подписном товаре Prodamus.

**Тексты** — в файле `bot/texts.py` (все 6 сообщений из ТЗ лежат там дословно).

Как отредактировать, не умея работать с сервером:
1. FileZilla (шаг 5) → справа зайдите в `/opt/obshchestvo-tayn`;
2. найдите нужный файл → правой кнопкой → **«Просмотр/Редактирование»** → откроется в Блокноте;
3. поправьте текст (меняйте только то, что внутри кавычек) → сохраните (Ctrl+S) → FileZilla сам загрузит файл обратно;
4. примените изменения — в консоли сервера:
   ```bash
   cd /opt/obshchestvo-tayn && docker compose restart bot
   ```

## Если что-то не работает

| Симптом | Причина | Что делать |
|---|---|---|
| Бот не отвечает на /start | неверный `BOT_TOKEN` или контейнер упал | `cd /opt/obshchestvo-tayn && docker compose logs -f bot` — там будет причина |
| «Не получилось создать ссылки» | бот не админ в канале/чате или нет права «Приглашать» | Шаг 2, проверить галочки |
| `/admin` не открывается | неверный `ADMIN_IDS` | узнать ID через @userinfobot, поправить в `.env`, перезапустить |
| Prodamus «Тестировать запрос» → ошибка | неверный адрес вебхука | должен быть `https://домен/prodamus/webhook` |
| Оплата прошла, а доступа нет | подпись не совпала (не тот секретный ключ) или демо-режим Prodamus | проверить `PRODAMUS_SECRET`, включить боевой режим; в логах будет «неверная подпись» |
| Пришло «Платёж пришёл, но пользователя не удалось определить» | Prodamus не передал данные пользователя | `/admin` → 🎁 Выдать доступ вручную (это на 10 секунд) |
| Автосписания не происходят | не задан `PRODAMUS_SUBSCRIPTION_ID` | добавить ID подписного товара в `.env`, перезапустить |
| Оплата «не открывается»: страница Prodamus сразу возвращает на главную | форма не приняла подпись ссылки | на сервере: `cd /opt/obshchestvo-tayn && docker compose exec bot python scripts/check_prodamus.py` — скрипт скажет, принимает ли форма подпись |
| «Отменить подписку» пишет «Prodamus не подтвердил» | Prodamus не узнал клиента (нет телефона/привязки) | отключить вручную в кабинете Prodamus: «Подписчики» → найти → выключить «Статус» |

Полезные команды на сервере:

```bash
cd /opt/obshchestvo-tayn
docker compose logs -f bot        # смотреть, что происходит (Ctrl+C — выйти)
docker compose restart bot        # перезапустить бота
docker compose down && docker compose up -d   # полностью перезапустить

# проверить настройки (что заполнено / есть ли доступ к каналу и чату):
docker compose exec bot python scripts/check_setup.py

# проверить связку с Prodamus (принимает ли форма наши ссылки):
docker compose exec bot python scripts/check_prodamus.py
```

## Безопасность — 3 правила

1. **Токен бота и секретный ключ Prodamus — как пароль от банка.** Никому не пересылайте, не публикуйте, не вставляйте в переписки. Если что-то утекло — перевыпустите токен у BotFather и ключ в Prodamus.
2. **Пароль от сервера** храните в надёжном месте (менеджер паролей).
3. **Резервная копия.** Вся база — один файл `data/club.db`. Раз в неделю можно скачать его через FileZilla из `/opt/obshchestvo-tayn/data/` — этого достаточно, чтобы «всё вернуть» в случае чего.

## Мини-словарь

- **Бот** — аккаунт в Telegram, который отвечает автоматически.
- **Вебхук** — «звонок» от Prodamus боту: «этот человек оплатил». Приходит на адрес `https://домен/prodamus/webhook`.
- **Рекуррент / автосписание** — автоматическое списание денег каждый месяц с карты подписчика.
- **VPS / сервер** — круглосуточно включённый компьютер в интернете, где живёт бот.
- **Контейнер / Docker** — «коробка», в которой запущен бот; чтобы обновить или перезапустить, не нужно ничего настраивать заново.
- **ADMIN_IDS** — ваш Telegram ID, по которому бот понимает, что вы главная.
