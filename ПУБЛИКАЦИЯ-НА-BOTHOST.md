## Шаг 1. Не создавать бота сейчас

Нажать «Отмена» на форме. Причина не в тарифе, а в токене: тот, что сейчас в `.env`,
засветился в переписке и годен только для локальных тестов.

**BotFather → `/mybots` → ваш бот → API Token → Revoke** → новый токен сохранить,
он понадобится в шаге 4.

## Шаг 2. Отправить тикет в Bothost (до оплаты)

«Тикеты поддержки» в кабинете или `@bothost_ru` в Telegram:

> Здравствуйте! Планирую разместить у вас Telegram-бота (Python 3.11+, aiogram 3,
> long polling, SQLite) — бота закрытого клуба с оплатой подписки.
>
> 1. Помимо Telegram бот принимает вебхуки от платёжной системы Prodamus на собственный
>    HTTP-адрес, например `https://bot-XXX.bothost.ru/prodamus/webhook`. Пробрасывается ли
>    весь входящий трафик на порт приложения, или только телеграм-вебхук? Могу ли я принимать
>    POST-запросы от стороннего сервиса на произвольный путь?
> 2. Есть ли на платном тарифе постоянное дисковое хранилище, не стирающееся при перезапуске
>    контейнера? Нужно хранить файл SQLite с подписками.
> 3. Работает ли приложение круглосуточно без «засыпания» на тарифе Базовый и перезапускается
>    ли автоматически при падении?
> 4. Используется ли мой `Dockerfile` из репозитория или вы собираете образ сами?
>
> Заранее спасибо!

Ответ на вопрос 1 — решающий. Если путь не пробрасывается, вариант всё равно есть
(вынести приём платежей отдельно), но это надо знать до оплаты.

## Шаг 3. Положить проект в GitHub

Проект уже в git. Дальше два пути.

### Вариант А — через сайт GitHub (без терминала)

1. `github.com` → **New repository** → имя `obshchestvo-tayn-bot` → **Public** → Create.
2. На странице пустого репозитория — ссылка **«uploading an existing file»**.
3. Перетащите туда **содержимое** папки проекта (не саму папку), кроме `.env` и `data/`.
4. Commit changes.

### Вариант Б — через терминал на Mac

Скачать архив проекта, распаковать, затем в терминале:

```bash
cd obshchestvo-tayn-bot
git init -b main
git add -A
git commit -m "Бот клуба «Общество тайн»"
git remote add origin https://github.com/ВАШ_ЛОГИН/obshchestvo-tayn-bot.git
git push -u origin main
```

`.env` не уйдёт — он в `.gitignore`. Проверить можно так: на GitHub в списке файлов
`.env` быть не должно.

На платном тарифе появится раздел «Переменные окружения». Перенести туда значения

| `CHAT_ID` | `-1004458135206` |
| `PRODAMUS_SECRET` | секрет Prodamus (лучше перевыпустить) |
| `PRODAMUS_FORM_URL` | `https://prostranstvosimvolov.payform.ru/` |
| `PRICE` | `790` |
| `SUBSCRIPTION_DAYS` | `30` |

| `PUBLIC_BASE_URL` | `https://bot-XXX.bothost.ru` (адрес выдаст платформа) |

| `PRODAMUS_SUBSCRIPTION_ID` | оставить пустым, пока робот не подключён |

## Шаг 6. Что проверить после запуска

- [ ] в логах BotHost видно `Run polling for bot @society_secrets_bot`;
- [ ] `/start` в Telegram отвечает приветствием;
- [ ] `/admin` доступен только с `400344217`;
- [ ] `POST` на `https://bot-XXX.bothost.ru/prodamus/webhook` возвращает `success`;
- [ ] Prodamus: «Тестировать запрос» в настройках уведомлений → `success`;
- [ ] пробный платёж 790 ₽ (можно вернуть) → приходят ссылки в канал и чат;
- [ ] перезапуск бота не стирает базу (проверить, что подписка осталась).

## Когда уходить с Bothost на VPS

- поддержка не подтвердила проброс вебхука Prodamus;
- база стирается при перезапуске;
- платформа «бета» и тикеты обрабатываются до 48 часов, а бот уже принимает деньги.

В этих случаях — VPS за 279–390 ₽ и `deploy/install.sh`, всё уже готово.
