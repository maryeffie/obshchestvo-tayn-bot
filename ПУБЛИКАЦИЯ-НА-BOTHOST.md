# Этап 2. Положить код на GitHub (10 минут)

Bothost умеет забирать код только из Git-репозитория, поэтому нужен GitHub.
Аккаунт бесплатный.

### 2.1. Создать репозиторий

1. Откройте `github.com` → **Sign up** (если аккаунта нет) или **Sign in**.
2. Справа вверху **+** → **New repository**.
3. Заполнить:
   - **Repository name:** `obshchestvo-tayn-bot`
   - **Public** (обязательно публичный — иначе Bothost не сможет забрать код)
   - галочки про README и .gitignore **не ставить**
4. **Create repository**.

### 2.2. Загрузить файлы

1. Скачайте `obshchestvo-tayn-bot-github.zip` и распакуйте (двойной клик).
2. Появится папка `obshchestvo-tayn-bot` — **откройте её**. Внутри должны быть `bot`, `tests`,
   `run.py`, `requirements.txt`, `Dockerfile` и другие файлы.
3. На странице пустого репозитория нажмите ссылку **«uploading an existing file»**.
4. Выделите **всё содержимое** папки (Cmd+A внутри папки, не саму папку) и перетащите в окно браузера.
5. Дождитесь, пока файлы загрузятся (может занять минуту).
6. Внизу **Commit changes**.

Проверка: на странице репозитория видно папки `bot`, `tests`, `deploy` и файлы `run.py`, `main.py`,
`Dockerfile`, `requirements.txt`. **Файла `.env` быть не должно** — если он там появился, удалите
его (открыть файл → корзина → Commit changes): в нём лежат токен и секрет.

### 2.3. Скопировать адрес репозитория

Зелёная кнопка **Code** → **HTTPS** → скопировать строку вида
`https://github.com/ВАШ_ЛОГИН/obshchestvo-tayn-bot.git`

# Если в стартовом сообщении вебхук вида http://0.0.0.0:8080/...

Это значит, что `PUBLIC_BASE_URL` не задан и бот показывает внутренний адрес контейнера.
Снаружи по нему никто не постучится, Prodamus не сможет сообщить об оплате.

Лечение:

1. В карточке бота найти публичный адрес вида `https://bot-123.bothost.ru`.
2. В переменных окружения добавить `PUBLIC_BASE_URL` = этот адрес (без слэша на конце).
3. **Удалить** переменную `WEBHOOK_PORT`: платформа сама передаёт порт через `PORT`,
   а жёстко заданный 8080 может конфликтовать с её прокси. `WEBHOOK_HOST` оставить `0.0.0.0`.
4. Перезапустить бота. В новом стартовом сообщении должно быть
   `Вебхук: https://bot-123.bothost.ru/prodamus/webhook`.
5. Этот адрес вписать в Prodamus в оба поля уведомлений → «Тестировать запрос» → ждём `success`.

Если после этого Prodamus отвечает ошибкой — платформа не пропускает внешние запросы
на произвольный путь. Тогда писать в поддержку Bothost и, скорее всего, переезжать на VPS.

## Оплата из-за рубежа: бессрочная ссылка с конвертацией

Prodamus подтвердил: **подписка с автосписанием возможна только по картам РФ и только в рублях**.
Для покупателей из других стран Марина создала в кабинете **бессрочную ссылку**
`https://payform.ru/g7d0lTx/` — на ней сумма пересчитывается в валюту плательщика
по курсу банка на день оплаты.

Она прописана в переменной **`PRODAMUS_FOREIGN_URL`**. Бот добавляет к ней свои параметры
(`order_id`, `customer_extra=tg:ID`, подпись), чтобы по уведомлению понять, кто заплатил.

**Как выглядит для человека:** «Оплатить в другой валюте» → текст «Тайны не знают границ!» →
кнопка «Перейти к оплате» → страница Prodamus с его валютой. После оплаты бот выдаёт
ссылки в канал и чат на 30 дней. Автопродления нет, напоминание за 3 дня, «Продлить подписку»
ведёт снова на ту же бессрочную ссылку.

**Цен в валюте бот не хранит.** Сумма считается на стороне Prodamus по курсу банка
на день оплаты — в боте нет ни фиксированных цен в евро, ни выбора валюты.

**Если `PRODAMUS_FOREIGN_URL` пуст**, кнопка «Оплатить в другой валюте» просто не показывается.
Чтобы выключить оплату из-за рубежа — очистите эту переменную.

**Что обязательно проверить после деплоя:**

1. Бот: «Оплатить» → «Оплатить в другой валюте» → кнопка «Перейти к оплате».
2. Посмотреть в адресной строке, что в ссылке сохранились параметры `order_id` и
   `customer_extra` (если Prodamus их обрезает — напишите, переключимся на запасной вариант).
3. Одна реальная оплата небольшой суммой: дойдёт ли уведомление и откроется ли доступ
   автоматически. Если человек не определился — сработает кнопка «Я оплатил — проверить».

## Навигация и переменные после правок

| Переменная | Значение | Зачем |
| ---------- | -------- | ----- |
| `PRODAMUS_FOREIGN_URL` | `https://payform.ru/g7d0lTx/` | бессрочная ссылка для оплаты из-за рубежа |
| `PRODAMUS_URL_SUCCESS` | `https://t.me/society_secrets_bot` | кнопка «вернуться» после успешной оплаты ведёт в чат с ботом |
| `PRODAMUS_URL_RETURN` | `https://t.me/society_secrets_bot` | кнопка «вернуться в магазин» ведёт в чат с ботом |

Ссылка на оплату из-за рубежа и адрес возврата теперь прописаны в коде по умолчанию,
поэтому кнопка «Оплатить в другой валюте» показывается даже без переменных в Bothost.
Чтобы **выключить** оплату из-за рубежа, поставьте `PRODAMUS_FOREIGN_URL=off`.

## Защита адреса вебхука (по желанию, но рекомендую)

Адрес уведомлений у нас открытый: любой, кто его знает, может отправить поддельный
запрос. Подпись Prodamus мы проверяем, но если она когда-нибудь не сойдётся, бот
не станет открывать доступ сам — пришлёт админу кнопку «Выдать доступ».

Чтобы включить дополнительную защиту:

1. В Bothost задайте переменную `WEBHOOK_TOKEN` (случайная строка, например `obs-tayn-8fd41c`).
2. В кабинете Prodamus укажите адрес уведомлений с токеном:
   `https://bot-1794048359-1694-maryeffie.bothost.tech/prodamus/webhook?token=obs-tayn-8fd41c`
   (и в настройках подписки 3135187 — тот же адрес).
3. После этого запросы без верного `token` бот отклоняет, а платежи с верным токеном
   засчитываются даже если подпись Prodamus не совпала.

Без токена всё тоже работает: платежи с верной подписью засчитываются автоматически.

## Тестовая оплата за 1 ₽ (команда `/pay1`)

Команда доступна **любому пользователю**, но только пока включена в настройках:

| Переменная | Значение | Смысл |
| ---------- | -------- | ----- |
| `PAY1_ENABLED` | `true` | включить тестовые оплаты |
| `PAY1_LIMIT` | `10` | сколько всего таких ссылок можно выдать |

- Каждое использование приходит админу уведомлением: кто и сколько осталось.
- Когда проверка закончится — поставьте `PAY1_ENABLED=false` (или уберите переменную).
  Команда ответит «тестовая оплата выключена» и перестанет выдавать ссылки.
- Ссылка создаётся боевая: скидка 789 ₽ применяется только к этому платежу,
  цена в Prodamus и в боте остаётся 790 ₽.

**Важно:** это настоящие деньги (1 ₽). После проверки обязательно выключите команду.

## Как добавить администратора (например, Марину)

Два способа — оба рабочие, можно пользоваться любым.

**Способ 1 — прямо в боте (без Bothost, ничего не пересобирать):**

1. Откройте `/admin` → кнопка **«👥 Администраторы»**.
2. Нажмите **«➕ Добавить администратора»**.
3. Перешлите боту любое сообщение от Марины — или пришлите её числовой ID `2138023308`.
4. Готово: Марина сразу получает уведомления об оплатах и может открывать `/admin`.

Убрать такого администратора — кнопка **«❌ Убрать …»** в том же списке. Настройка
хранится в базе (`data/club.db`, таблица `admins`), поэтому переживает перезапуск
и пересборку. Кого нельзя убрать — это главный администратор из `ADMIN_IDS`.

**Способ 2 — через Bothost (переменная окружения):**

| Переменная | Было | Стало |
| ---------- | ---- | ----- |
| `ADMIN_IDS` | `400344217` | `400344217,2138023308` |

После правки — перезапустить бота. Здесь перечислены «главные» администраторы:
они получают уведомления всегда и убрать их из бота нельзя.

## Ссылки-приглашения: сколько живут и сколько раз открываются

| Переменная | По умолчанию | Смысл |
| ---------- | ------------ | ----- |
| `INVITE_LINK_TTL_HOURS` | `24` | через сколько часов ссылка перестаёт действовать |
| `INVITE_LINK_USES` | `3` | сколько раз по одной ссылке можно войти (`0` — без ограничений) |

Раньше ссылка была ровно на один вход, и Telegram показывал
«This invite link has expired» уже при втором нажатии — например, когда человек
открыл её на телефоне и на компьютере. Теперь входов три, срок прежний — 24 часа.

Если у участника всё-таки «ссылка недействительна»:

- он сам: в боте «📅 Моя подписка» → «🔗 Получить новые ссылки»;
- админ: команда `/links 2138023308` — отправит свежие ссылки в канал и чат.
