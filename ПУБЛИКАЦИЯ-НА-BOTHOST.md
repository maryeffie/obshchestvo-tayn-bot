# Этап 2. Положить код на GitHub (10 минут)

Bothost умеет забирать код только из Git-репозитория, поэтому нужен GitHub.
Аккаунт бесплатный.

### 2.1. Создать репозиторий

1. Откройте `github.com` → **Sign up** (если аккаунта нет) или **Sign in**.
2. Справа вверху **+** → **New repository**.
3. Заполнить:
   - **Repository name:** `obshchestvo-tayn-bot`
   - **Public** (обязательно публичный — иначе Bothost не сможет забрать код)
   - галочки про README и .gitignore **не ставить**
4. **Create repository**.

### 2.2. Загрузить файлы

1. Скачайте `obshchestvo-tayn-bot-github.zip` и распакуйте (двойной клик).
2. Появится папка `obshchestvo-tayn-bot` — **откройте её**. Внутри должны быть `bot`, `tests`,
   `run.py`, `requirements.txt`, `Dockerfile` и другие файлы.
3. На странице пустого репозитория нажмите ссылку **«uploading an existing file»**.
4. Выделите **всё содержимое** папки (Cmd+A внутри папки, не саму папку) и перетащите в окно браузера.
5. Дождитесь, пока файлы загрузятся (может занять минуту).
6. Внизу **Commit changes**.

Проверка: на странице репозитория видно папки `bot`, `tests`, `deploy` и файлы `run.py`, `main.py`,
`Dockerfile`, `requirements.txt`. **Файла `.env` быть не должно** — если он там появился, удалите
его (открыть файл → корзина → Commit changes): в нём лежат токен и секрет.

### 2.3. Скопировать адрес репозитория

Зелёная кнопка **Code** → **HTTPS** → скопировать строку вида
`https://github.com/ВАШ_ЛОГИН/obshchestvo-tayn-bot.git`

# Если в стартовом сообщении вебхук вида http://0.0.0.0:8080/...

Это значит, что `PUBLIC_BASE_URL` не задан и бот показывает внутренний адрес контейнера.
Снаружи по нему никто не постучится, Prodamus не сможет сообщить об оплате.

Лечение:

1. В карточке бота найти публичный адрес вида `https://bot-123.bothost.ru`.
2. В переменных окружения добавить `PUBLIC_BASE_URL` = этот адрес (без слэша на конце).
3. **Удалить** переменную `WEBHOOK_PORT`: платформа сама передаёт порт через `PORT`,
   а жёстко заданный 8080 может конфликтовать с её прокси. `WEBHOOK_HOST` оставить `0.0.0.0`.
4. Перезапустить бота. В новом стартовом сообщении должно быть
   `Вебхук: https://bot-123.bothost.ru/prodamus/webhook`.
5. Этот адрес вписать в Prodamus в оба поля уведомлений → «Тестировать запрос» → ждём `success`.

Если после этого Prodamus отвечает ошибкой — платформа не пропускает внешние запросы
на произвольный путь. Тогда писать в поддержку Bothost и, скорее всего, переезжать на VPS.

## Оплата в иностранной валюте: вручную через Марину

1. Кнопка «Оплатить в другой валюте» показывает сообщение и кнопку «Получить ссылку на оплату» → `https://t.me/m/gavHrzZfNjFk`. Новые зарубежные заказы бот не создаёт. В напоминаниях о продлении этот путь также доступен; рублёвая оплата остаётся прежней. Промокод в боте применяется к рублёвой форме; применение к ручной оплате уточняет Марина.
2. Владелец ссылки должен заранее настроить в Telegram Business текст для этой бизнес-ссылки:

   > Добрый день! Хочу присоединиться к закрытому клубу «Общество тайн». Подскажите, пожалуйста, как получить ссылку на оплату и доступ в клуб?

   Текст хранится в Telegram, не в параметрах ссылки и не в коде бота. Проверьте переход с другого аккаунта: Telegram должен подставить текст в поле ввода; пользователь сам его отправляет. Содержимое ссылки не проверено автоматически.
3. Марина самостоятельно создаёт персональную ссылку в Prodamus и отправляет её участнику. После подтверждения оплаты в кабинете, а не по сумме или времени, она запрашивает @username и сверяет Telegram ID (участник узнаёт его командой `/myid` в боте). Участник должен сначала запустить бота; иначе бот не сможет прислать приглашения. Поиск @username работает только по сохранённым в базе именам, которые могут устареть или быть переиспользованы. Обязательно сверяйте показанный ботом ID с участником перед выдачей.
4. `/admin` → «🎁 Выдать доступ» → ID или сохранённый @username → проверьте показанного участника и ID → введите срок. При продлении срок добавляется к неистёкшему. При ошибке отправки доступ может уже быть сохранён: проверьте карточку, прежде чем повторять. Ручная выдача не останавливает автосписание в Prodamus и не записывает оплату как выручку.

Старые заказы и подписанные webhook обрабатываются как прежде. Если нет надёжной привязки, доступ не назначается автоматически; не сопоставляйте платежи только по времени или сумме. Сверьте исторические спорные назначения и платёж 51283964 в production DB с подтверждёнными данными; автоматически ничего не переносите. До обновления сделайте резервную копию постоянной базы Bothost. Контакты старых платежей не становятся подтверждёнными автоматически.

### Настройки

`PRODAMUS_FOREIGN_URL` и `PRODAMUS_FOREIGN_DYNAMIC` оставлены для совместимости старого кода, но больше не управляют пользовательской валютной кнопкой или напоминаниями. В частности, `PRODAMUS_FOREIGN_URL=off` не скрывает кнопку. `PRODAMUS_URL_SUCCESS` и `PRODAMUS_URL_RETURN` по-прежнему задают возврат из платёжной формы.

Перед выкладкой проверьте в Bothost постоянный том, резервную копию и адрес webhook; в Prodamus — подпись и контролируемую рублёвую оплату. Реальная зарубежная форма или ручной платёж этими тестами не проверены.

## Тестовая оплата за 1 ₽ (команда `/pay1`)

## «Ссылка недействительна» у конкретного человека: команда `/check`

Если свежая ссылка всё равно не пускает — дело не в ссылке, а в состоянии
человека в канале. Проверка одной командой:

```
/check 2138023308
```

Бот ответит статусами:

| Статус | Что значит | Что делать |
| ------ | ---------- | ---------- |
| `уже внутри` | человек в канале/чате | вступать не нужно — ошибка «ссылка недействительна» появляется именно здесь |
| `уже внутри (владелец канала)` | это ваш канал | ссылка не нужна, он и так внутри |
| `вышел сам — ссылка сработает` | покинул чат | жать свежую ссылку |
| `был заблокирован (выгнан)` | остаточный бан | бот снимает бан и присылает ссылки |
| `не состоит — ссылка сработает` | ни разу не вступал | жать свежую ссылку |

Команда сразу снимает бан в канале и чате (`unbanChatMember`) и отправляет
участнику новые ссылки — то же самое теперь происходит и при каждой оплате,
и при кнопке «🔗 Получить новые ссылки».

То же самое кнопкой: админ-панель → «👤 Найти участника» → прислать
`@username` или ID → в карточке участника нажать **«🔎 Проверить вход в канал»**.

Вручную: канал → «Управление» → «Участники» → вкладка
«Удалённые / Заблокированные» → найти человека → «Разблокировать».
