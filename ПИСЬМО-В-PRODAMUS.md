Подскажите, пожалуйста, по трём пунктам:

- метод API для **инициации повторного списания по сохранённой карте** клиента

  остаётся обычной (ставка эквайринга по банковским картам) — то есть вариант

**3. Если бесплатные варианты невозможны.** Какая минимальная стоимость подключения

Пока ждём ответ, работаем в режиме ручного продления: напоминания и оплата по ссылке —

## Что важно помнить

- Автосписания у Prodamus работают **только с карт РФ** — это их ограничение, не наше.
- «Свой робот» без их API физически не сможет списывать деньги: данные карт хранит
  платёжная система, а не мы. Поэтому главный вопрос в письме — именно про API
  инициирования списания.
- Если ответят «бесплатно нельзя» — ничего страшного: клуб запускаем на ручном
  продлении (это уже готово и работает), а робота включаем позже, когда доход
  от подписок будет заметно больше 3000 ₽ + 1%.
